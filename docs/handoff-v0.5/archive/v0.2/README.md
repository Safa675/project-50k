## Locked decisions reflected in v0.1

- Turkey-first retail investor product.
- Asset priority: BIST → Turkish investment funds → crypto → U.S. equities.
- BIST must support intraday intelligence.
- Funds are a strategic USP, not a secondary module.
- Crypto MVP includes market + selected on-chain intelligence, initially EVM + Solana.
- U.S. equity MVP uses a restricted liquid universe.
- Social-media monitoring is outside MVP; trusted news is in scope.
- AI-native hybrid architecture: deterministic/statistical signals + AI investigation/reasoning + normalized event engine.
- Severity and confidence are separate concepts.
- Material AI claims require sources; the assistant must be able to state that evidence is insufficient.
- No Buy/Hold/Sell recommendations.
- Account-based product with anonymous public browsing and Google-only authentication for personal features.
- Watchlist = My Assets for MVP; no quantity/cost-basis accounting.
- Personal watchlist alerts plus Critical-only market-wide alerts.
- In-app + e-mail for MVP; no browser push.
- Minimal protected admin operations dashboard.
- Responsive web MVP; long-term product is mobile-first.
- Natural Turkish UI; English engineering artifacts.
- High design-quality requirement; no generic AI-generated fintech aesthetic; Impeccable used as an agentic design-quality tool.
- Historical replay is the primary jury-proof mechanism, with current/live ingestion as supporting proof.
